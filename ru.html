Почему это удобно

Четыре фичи, которые делают релизы весёлыми.

50 MR одной вставкой

Скопируйте список веток в текстовое поле, выберите цель — и инструмент создаст merge request для каждой. Никакого бесконечного кликанья.

GitLab · GitHub · Bitbucket

Один дашборд, три провайдера. Одинаковый интерфейс, одинаковая логика. Никаких переключений между разными интерфейсами.

Auto-merge для ленивых, Dry-Run для параноиков

Проверьте конфигурацию тестовым прогоном. Потом нажмите auto-merge — и пусть система делает всё сама. Мы не осуждаем, мы автоматизируем.

Шаблоны + История = Ноль повторений

Сохраните конфигурацию проекта как шаблон один раз. Воспроизведите любой MR из истории одним кликом. Идеально для пятничных hotfix'ов, когда мозг уже выключен.

Как это работает

Три шага. И всё.

1

Добавьте провайдера

Подключите GitLab, GitHub или Bitbucket. Введите API URL и токен — один раз. Они зашифрованы, мы их не видим.

2

Вставьте ветки

5 веток? 50 веток? Вставьте все сразу. Можно загрузить список веток напрямую из репозитория.

3

Нажмите кнопку

Нажмите «Создать» — или запустите dry-run, чтобы сначала проверить. Наблюдайте за прогрессом в реальном времени и получите отчёт.
